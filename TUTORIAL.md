## 🤖 **PASSO 4: CONFIGURANDO AUTO-STEAL**

### **Para Iniciantes:**
1. Vá para aba **🤖 Auto-Steal**
2. Configure **Método**: "Smart" (recomendado)
3. Configure **Alcance**: 50 studs
4. Ative **Teleportar para Target**
5. Ative **Evitar Jogadores**
6. Clique **▶️ Iniciar**

### **Configurações Avançadas:**
- **Nearest**: Pega o mais próximo (rápido)
- **Valuable**: Foca nos mais valiosos (eficiente)
- **Smart**: IA balanceia valor/distância (melhor)
- **Random**: Aleatório (mais natural)

### **Dicas:**
- Use **Apenas Raros** em servers lotados
- Aumente **Valor Mínimo** se quiser focar em melhores
- Reduza **Delay** para mais velocidade

## 👁️ **PASSO 5: CONFIGURANDO ESP**

### **ESP Básico:**
1. Vá para aba **👁️ ESP**
2. Ative **👥 ESP de Jogadores**
3. Ative **🧠 ESP de Brainrots**

### **Tipos de ESP:**

- **Items**: Moedas, upgrades, power-ups

### **Cores do ESP:**
- **Vermelho**: Jogadores
- **Verde**: Brainrots comuns
- **Amarelo**: Brainrots raros
- **Azul**: Items e áreas

## 🚨 **PROBLEMAS COMUNS E SOLUÇÕES**

### **❌ "HTTP não habilitado"**
**Solução**: Habilite HTTP requests no seu executor

### **❌ Script não carrega**
**Soluções**:
- Verifique conexão com internet
- Tente URL backup
- Reinicie Roblox
- Use executor diferente

### **❌ ESP não aparece**
**Soluções**:
- Verifique se está ativado
- Pressione F8 para escanear
- Reduza distância máxima
- Limpe ESP e reative

### **❌ Auto-steal não funciona**
**Soluções**:
- Verifique se há brainrots no mapa
- Reduza valor mínimo
- Aumente distância de busca
- Reinicie auto-steal

### **❌ Lag/Performance baixa**
**Soluções**:
- Reduza distância ESP
- Desative ESP desnecessários
- Feche outros scripts
- Reinicie o hub
