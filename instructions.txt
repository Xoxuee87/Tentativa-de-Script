2. 🎮 INTERFACE E CONTROLES
=============================================

HOTKEYS (TECLAS DE ATALHO):
📝 INSERT - Abrir/Fechar GUI principal
⚡ F1 - Ativar/Desativar velocidade aumentada
👻 F2 - Ativar/Desativar invisibilidade
👥 F3 - Ativar/Desativar ESP de jogadores
🧠 F4 - Ativar/Desativar ESP de brainrots
🚜 F5 - Ativar/Desativar auto-farm

NAVEGAÇÃO DA GUI:
🏠 Principal - Status e controles principais
👁️ ESP - Configurações de visualização
🚜 Farm - Controles de coleta automática
🏃 Movimento - Velocidade e invisibilidade
🌐 Servidores - Mudança de servidor
📝 Logs - Histórico de ações

CONTROLES:
🖱️ Clique e arraste - Mover a janela
❌ Botão X - Fechar GUI (ou INSERT)
🔘 Botões coloridos - Verde=Ativo, Vermelho=Inativo

3. 🎯 FUNCIONALIDADES PRINCIPAIS
=============================================

AUTO-FARM INTELIGENTE:
🎯 Coleta automaticamente os brainrots mais valiosos
💎 Prioriza brainrots raros primeiro
📏 Calcula melhor rota (valor/distância)
⚡ Teleporte instantâneo para targets
🔄 Scan contínuo por novos brainrots
⚙️ Configurável (valor mínimo, distância, etc.)

COMO USAR:
1. Abra a aba "Farm"
2. Clique em "Iniciar Auto Farm"
3. O script fará tudo automaticamente
4. Monitor os logs para ver progresso

ESP (VISUALIZAÇÃO):
👥 Jogadores - Mostra nome e distância
🧠 Brainrots - Localização de todos brainrots
💎 Brainrots Raros - Destaque especial
⏰ Timer de Base - Countdown de proteção
📏 Linhas conectoras - Do seu personagem aos objetos
🎨 Cores customizáveis

COMO USAR:
1. Abra a aba "ESP"
2. Ative os tipos desejados
3. Objetos aparecerão com caixas coloridas
4. Linhas mostram direção

MOVIMENTO AVANÇADO:
💨 Velocidade - 16 → 50+ walkspeed
🦘 Pulo Alto - 50 → 120+ jumppower
👻 Invisibilidade - Torna-se invisível
📍 Teleporte - Para brainrots ou spawn

COMO USAR:
1. Use hotkeys F1, F2 para ativar rapidamente
2. Ou use a aba "Movimento"
3. Combine habilidades para máxima eficiência

SERVER HOPPING:
🔍 Procura servidores com brainrots raros
🔄 Muda automaticamente de servidor
📊 Conta servidores verificados
⏹️ Para quando encontrar raros

COMO USAR:
1. Abra a aba "Servidores"
2. Clique "Iniciar Busca por Raros"
3. Aguarde encontrar servidor bom
4. Para manualmente se necessário

5. 💡 DICAS E TRUQUES
=============================================

MAXIMIZANDO EFICIÊNCIA:
🎯 Configure valor mínimo alto para focar em raros
👻 Use invisibilidade em servidores lotados
⚡ Velocidade máxima para movimentação rápida
🔍 ESP de raros para encontrar tesouros
🌐 Server hop quando servidor está vazio

ESTRATÉGIAS AVANÇADAS:
🕐 Farm durante horários menos movimentados
🎭 Alterne entre invisível e visível
📊 Monitor logs para otimizar configurações
🎯 Focar em brainrots raros específicos
🔄 Reiniciar script se necessário

SEGURANÇA:

🕐 Use delays maiores se suspeitar de anti-cheat

👀 Monitore outros jogadores suspeitos
🔇 Mantenha perfil baixo

PERFORMANCE:
📉 Reduza distância ESP se estiver com lag
🧹 Limpe ESP periodicamente
🔄 Reinicie script se consumir muita memória
⚡ Feche outros scripts desnecessários

6. 🔧 SOLUÇÃO DE PROBLEMAS
=============================================

PROBLEMAS COMUNS:

❌ "HTTP não habilitado"
SOLUÇÃO: Habilite HTTP requests no seu executor

❌ Script não carrega
SOLUÇÕES:
- Verifique conexão com internet
- Tente URL backup
- Reinicie Roblox
- Use executor diferente

❌ ESP não aparece
SOLUÇÕES:
- Verifique se está ativado
- Escaneie por brainrots primeiro
- Reduza distância máxima
- Limpe ESP e reative

❌ Auto-farm não funciona
SOLUÇÕES:
- Verifique se há brainrots no mapa
- Reduza valor mínimo
- Aumente distância de busca
- Reinicie auto-farm

❌ Invisibilidade não funciona
SOLUÇÕES:
- Alguns executores têm limitações
- Tente apenas velocidade
- Reinicie personagem
- Use executor mais avançado

❌ Lag/Baixa Performance
SOLUÇÕES:
- Reduza distância ESP
- Desative ESP desnecessários
- Feche outros scripts
- Reinicie script

❌ Detectado por anti-cheat
SOLUÇÕES:
- Reduza velocidade
- Aumente delays
- Pare temporariamente
- Use modo stealth
